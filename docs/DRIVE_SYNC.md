# Drive 同步与备份

适合两台私人电脑交替使用。程序、AI 配置和授权凭据各自留在本机；词汇、单词本和逐次复习记录通过同一份私人 Drive 存储合并。没有连接云端时也能在本机使用。

单词本、词汇内容及复习历史会一起合并；旧版未分类词汇归入默认单词本。

## 方案一：Google Drive 桌面文件夹

推荐已安装 Drive 桌面版的用户使用，无需创建 Google Cloud 项目。

1. 两台电脑安装并登录 [Google Drive 桌面版](https://support.google.com/drive/answer/10838124?hl=zh-Hans)，使用同一个私人账号。
2. 在“我的云端硬盘”准备一个专用文件夹，例如 `Vocabulary Notebook`，设置为可离线使用。
3. 第一台电脑通过“设置与工具 → 云端同步”进入“同步与备份”页面，填写这个文件夹的本机绝对路径并连接。
4. 等待 Drive 桌面版上传完成。第二台电脑选择云端的同一个文件夹，等待完整下载后连接它；两台电脑盘符可以不同。
5. 各自在本机使用词汇本。默认每 30 秒自动合并，也可点击“立即同步”。

云端目录包含 `library.json` 身份标识及不可变的 `vocabulary-*.json` 操作文件。不要把整个程序、`.venv`、配置、`.secrets` 或本机 `words.json` 放进这个目录，不要手动修改或清空操作文件。第二台电脑应连接现有文件夹，避免新建同名空目录。

**“待写入文件夹为 0”仅代表应用已将变更交给本机文件夹，实际上传与下载由 Drive 桌面版完成。换电脑前确认桌面版已完成同步。**

## 方案二：Google Drive API 直连

适合不使用桌面版的电脑。与文件夹模式二选一，断开当前模式后才可切换。

1. 在 [Google Cloud](https://console.cloud.google.com/apis/library/drive.googleapis.com) 创建项目并启用 Google Drive API。
2. 配置 OAuth 同意屏幕，测试状态下添加自己的测试账号。
3. 创建“桌面应用”OAuth 客户端，下载 JSON。
4. 通过“设置与工具 → 云端同步”打开“同步与备份”页面，选择“Google Drive 直连”。导入客户端文件，点击连接，再点击“继续 Google 授权”，在 Google 页面完成授权。
5. 第二台电脑使用同一个客户端 JSON、同一个账号单独授权，不复制另一台的令牌。

只申请 `drive.appdata` 范围，数据位于应用的隐藏 `appDataFolder`，不会访问其他 Drive 文件，也不在普通文件列表中显示。见 [Google appDataFolder 文档](https://developers.google.com/workspace/drive/api/guides/appdata)。OAuth 使用本机回调、state 与 PKCE，令牌只留在各自的凭据目录。

授权等待期间可刷新页面或离开后返回，“继续 Google 授权”链接会保留到本次授权结束或超时。也可点击“取消授权”后重新连接，已取消的回调不会保存凭据。重启后端会结束尚未完成的授权，需要重新连接。

授权过期或网络不可用时，本地修改仍保留。页面会提示重新授权或重试；账户空间、API 配额和 Google 测试应用策略仍适用。

## 合并与学习记录

- 每台电脑保留独立缓存和设备 ID，不用整份词库覆盖云端。
- 不同字段的编辑都保留。同一字段的并发编辑按 Lamport 时钟、设备 ID、操作 ID 的固定顺序收敛。
- 每次评分是独立事件，重试传输不会重复评分。合并后按事件时间及 ID 重算 FSRS，保留两台电脑的学习记录；请保持系统时间正确。
- 删除标记优先于旧设备的编辑或评分，避免旧电脑把单词恢复出来。重新添加会产生新 ID。
- 两台电脑离线分别添加同一拼写时保留两条记录，避免误合并不同课程含义；同步后可自行检查重复项。
- 不自动清理历史或删除标记，以支持长期离线设备；操作文件会随使用增长，适合私人词库。

## 旧词库、备份与升级

首次读取旧版 `words.json` 时，保留 `words.json.legacy.bak`，再转换为带操作历史的本地缓存。旧词的 ID、释义和已有 FSRS 状态会作为基线保留；旧版本没有记录的逐次评分无法补造。

“同步与备份 → 下载完整备份”包含全部单词本、字段操作、删除标记和评分事件。导入时合并，不覆盖现有记录；兼容导入原项目的 `words.json`。普通列表的 PDF / CSV / JSON 导出只用于词汇整理，不能替代完整学习历史备份。

升级前停止应用，另存本地缓存、配置和凭据。不要把新缓存交给旧版程序直接写入；需要回退时保留升级后的数据，并谨慎使用迁移前副本，避免覆盖其他电脑的新记录。损坏文件或不兼容的版本会停止读取并保留原件。

## 配置和本机访问

在原 `config.json` 中可选添加：

```json
"sync": {
  "interval_seconds": 30,
  "credentials_dir": ".secrets"
}
```

原有 `provider`、`ollama`、`deepseek` 和 `srs` 配置保持有效。不连接 Drive 不需要凭据。凭据、实际配置、缓存及迁移副本已被 Git 忽略；完整备份不会包含 OAuth 令牌或 AI Key。

应用只监听 `127.0.0.1:1400`，校验实际连接地址、Host 与修改请求来源；README 中的开发命令和前端开发服务器也仅监听本机，后端关闭代理头解析，并对同一个缓存设置单进程锁。两台电脑分别在本机运行，通过 Drive 同步；此版本不再提供原来的局域网直接访问方式。云端数据沿用所选文件夹权限，请使用私人目录。

## 验证边界

自动测试使用临时目录、独立设备缓存和模拟 HTTP，覆盖离线双向合并、评分去重、删除、文件夹重启、失败重试、旧词库迁移、备份导入、单词本筛选和凭据隔离，不读取真实个人词库或令牌。

真实 Drive API OAuth 验收需要自己的 Google Cloud 客户端，自动测试不代表真实授权已经完成。文件夹模式可以用两个本地缓存验证合并，实际跨电脑传输还依赖 Drive 桌面版完成上传下载。

## 同步期间的编辑与补全

- 云端变更到达时，详情页刷新已保存的内容，保留正在编辑的单词、释义和单词本选择，并显示提示。点击保存会提交编辑框中的内容；取消则查看最新同步结果。如果单词被远端删除，保留草稿并提示先复制内容。
- AI 请求进行时，若单词移动到其他本，或课程名称、说明改变，旧结果会丢弃并提示重新补全，避免把原课程的解释写入新课程；不会自动再发起收费请求。
- UTC 时间支持 `Z` 和 `+00:00`，旧版不带时区的时间沿用北京时间规则。词库与评分记录不因兼容性修复而重写。

本机访问校验使用连接来源，不采用客户端填写的 `X-Forwarded-For`。自行启动 uvicorn 时也请使用 `--host 127.0.0.1 --no-proxy-headers`，不要通过局域网代理暴露本应用。

“设置与工具”菜单分别提供“模型设置”和“云端同步”入口，后者进入“同步与备份”页面。连接状态卡显示待同步数量、上次成功时间及手动同步按钮；切换同步方式前先断开当前方式。
